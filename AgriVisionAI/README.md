# AgriVisionAI

Dự án ứng dụng trí tuệ nhân tạo (AI/Computer Vision) trong nông nghiệp.

## Cấu trúc thư mục

```text
AgriVisionAI/
├── data/          # Chứa dữ liệu (raw, processed, external)
├── notebooks/     # Jupyter Notebooks cho EDA và thử nghiệm ban đầu
├── src/           # Mã nguồn chính của dự án (data loading, models, pipeline)
├── models/        # Lưu trữ mô hình đã huấn luyện (weights, checkpoints)
├── experiments/   # Nhật ký và kết quả các thực nghiệm
├── reports/       # Báo cáo, biểu đồ và kết quả đánh giá
├── configs/       # Các tệp cấu hình (hyperparameters, paths)
└── README.md      # Tài liệu hướng dẫn dự án
```
