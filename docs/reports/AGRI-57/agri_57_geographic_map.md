## Remaining limits

Natural Earth data are generalized and incomplete for tiny islands/reclaimed coastlines; reef metadata themselves report definition limitations ([provider](https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-reefs/)). Geographic groups are selected illustrative features, not official exhaustive boundary datasets. No expert GIS/survey/legal-boundary certification, satellite-image comparison, real-time map tiles, elevation interpretation or claim of100% positional accuracy. Canopy is decoration, not measured terrain.

Browser tests exercise inline hero plus programmatic/keyboard pan, not physical touch gestures or standalone-dialog visual certification. No screen-reader/physical-device/Safari/Firefox/FPS/coverage/GitHub Actions/real backend-model E2E. No Docker rebuild, migrations, volume operations, staging, commit, push, PR or Jira state change. Preserve earlier task evidence as historical.
